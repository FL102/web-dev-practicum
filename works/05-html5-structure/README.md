## Описание

Одностраничный сайт digital-специалиста: шапка с логотипом и меню, приветственный блок,
разделы «Обо мне», «Услуги», «Портфолио», «Опыт и образование», «Отзывы», боковая панель
с навыками, контактами и формой обратной связи, подвал.

Страница сверстана на HTML5 и CSS3 без JavaScript. Использованы семантические элементы
`header`, `nav`, `main`, `section`, `article`, `aside`, `footer`, а также `figure` / `figcaption`,
`time`, `address`, `blockquote`, форма с `label`.

В CSS применены внешняя таблица стилей, блочная модель, селекторы разных типов
(тег, класс, id, атрибут, псевдокласс, псевдоэлемент, составной), `:hover` и `:focus`,
`::before` / `::after`, `transition`, `transform`, `box-shadow`, `border-radius`, градиенты,
CSS Grid и Flexbox, медиазапросы для ширины 1100, 860 и 560 px.
